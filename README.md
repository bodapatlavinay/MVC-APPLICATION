**MVC CRUD Application for Student Management**

This is a Student Management System built with ASP.NET MVC and Entity Framework Core, providing full CRUD functionality with a SQL Server database backend.

**Features:**

**MVC Design Pattern:** Organized structure with Models, Views, and Controllers.

**CRUD Operations:** Create, Read, Update, and Delete students.

**Web API Integration:** Dedicated API controller with endpoints for GET, POST, PUT, and DELETE operations.

**Database:** SQL Server integration with the Students table to store student data (Name, Email, Age, Address).

**Responsive UI:** Built with Razor Pages and Bootstrap for a clean and responsive user interface.

**CORS Support:** Configured to allow cross-origin requests.

**Setup Instructions:**

**Clone the repository:**

git clone https://github.com/bodapatlavinay/MVC-APPLICATION.git

Configure the connection string in appsettings.json.

Set up the STUDENTDB database.

**Run the application:**

dotnet build
dotnet run

**Tech Stack:**

**Backend:** ASP.NET MVC, Entity Framework Core

**Frontend:** Razor Pages, Bootstrap

**Database: ** SQL Server
